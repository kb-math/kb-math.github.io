Simulating variable-speed wave equations

github.com/kb-math/wave_simulation
Plots waves travelling through space where the wave speed differs at each point. The example below shows an incoming light wave starting in a fast region (yellow, e.g. air), entering a slower region (blue, e.g. glass), then re-entering the original medium. Reflection and refraction are clearly visible.

This is simulated by solving a wave equation in which the wave speed is a function of space (rather than a constant). Analytic solutions are generally unavailable, so the finite-difference method is used.
